# Changelog

 **Christoffel's Kitchen** will be documented in this file.


### Added
- **Full Menu Item Management**: 
  - Added support to **edit** and **update** existing menu items directly from the interface[cite: 1].
  - Implemented real-time updates for deleting items with confirmation dialogs[cite: 1].
- **Search and Filter Capabilities**:
  - Added a search input bar to quickly find menu items by name[cite: 1].
  - Added interactive course filter chips (`Starter`, `Main`, `Dessert`, and `All`) to narrow down the displayed menu items[cite: 1].
  - Included a quick-clear option to reset searches and filters effortlessly[cite: 1].
- **Comprehensive Menu Statistics**:
  - Introduced a dedicated **Stats Tab** providing an overview of the menu[cite: 1].
  - Displays the total number of menu items, the average price of all dishes, and a breakdown count of items available in each course[cite: 1].
- **User Experience & Enhancements**:
  - Enhanced validation feedback using alerts when adding or updating menu items.
  - Refactored components and utilized `useMemo` for optimized search filtering and performance statistics.
  - Improved UI layout consistency across all active tabs and forms.
